# Locked Y Bridge — Fabric 1.20.6

功能：
- C 开启/关闭。
- 开启瞬间记录玩家脚下方块的 Y。
- 例如脚下方块 Y=24，则整个开启期间自动放置目标 Y 永远是 24。
- 玩家跳到 Y=25、26……不会把自动放置高度改成 25、26。
- 当前手持物必须是方块；不是方块时停止自动放置。
- 沿玩家水平朝向，最多预铺前方 3 格。
- 关闭后清除本次锁定状态。

## 构建
需要 JDK 21。

在项目目录运行：
`./gradlew build`

生成的 JAR 在：
`build/libs/locked-y-bridge-1.0.0.jar`

## 安装
把生成的 JAR 放入对应 Fabric 1.20.6 实例的 `mods` 文件夹，并安装 Fabric API。
